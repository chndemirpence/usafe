🚫 Censorship & Blocking Detector

Detect network interference, DNS manipulation, and blocked services

⚠️ Scope of these tests: a browser can only measure so much - even OONI's own browser-based tool (OONI Probe Web) publicly documents higher false-positive/negative rates than their native apps, and is explicitly not a replacement for them. Treat these results as an indicator worth investigating, not proof of censorship. In particular: connection-level blocking (TCP resets, SNI filtering - the technique most national firewalls actually use) cannot be distinguished from a CORS restriction or an ad/tracker blocker from inside a browser tab.

About USAFE

USAFE (Universal Security And Freedom Evaluator) is a client-side privacy toolkit.

All tests and encryption happen entirely in your browser - no data is ever sent to any server.

Features:

  • 🚫 Censorship/Blocking Detection
  • 👁️ Browser Fingerprint Analysis
  • 🔐 End-to-End Encrypted Messaging

Technical Stack:

  • Pure JavaScript (no frameworks)
  • Web Crypto API for encryption
  • No network requests - everything runs locally, including the vendored QR code library

Privacy

Nothing you enter here ever leaves your device. There is no backend for this app - every test, hash, and encryption/decryption operation runs in your browser's own JavaScript engine.

What that means in practice:

  • Messages, passwords, and files you encrypt or decrypt are processed entirely client-side and are never uploaded anywhere.
  • Key pairs are ephemeral - they exist only in this browser tab's memory and are gone on refresh, unless you copy them out yourself.
  • Fingerprint and hardware info collected on the Surveillance tab stays on this page; it is only shown to you and, if you choose, included in an exported report you save yourself.

What does leave your device (and why):

  • The Censorship tests make real network requests - to DNS-over-HTTPS resolvers (Cloudflare/Google/Quad9), IP-lookup services, and the sites being tested - because that's what those tests are measuring. No results from these requests are sent anywhere except back to your own screen.

USAFE is open source - you don't have to take this page's word for it, you can read the code.
